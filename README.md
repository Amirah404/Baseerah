# 🔮 مشروع بَصِيرَة | نظام الإنذار المبكر الذكي
**إعداد:** أميره الرشيدي (محللة ومهندسة بيانات)

### 📌 عن المشروع
"بَصِيرَة" هو نظام إنذار مبكر تفاعلي تم تطويره لخدمة القطاع غير الربحي (جمعية كفاءات). يهدف النظام إلى تقليل الهدر المالي والتشغيلي من خلال التنبؤ بنسب "التسرب" من البرامج قبل إطلاقها، بناءً على تحليل الأداء التاريخي وابتكار مقياس استراتيجي جديد يُعرف بـ **"مؤشر الالتزام"**.

### 🛠️ التقنيات المستخدمة
* **لغة البرمجة:** Python 🐍
* **معالجة البيانات:** Pandas & NumPy 📊
* **الواجهة التفاعلية (Dashboard):** Streamlit 💻
* **الرسوم البيانية:** Plotly 📈

### 🚀 الميزات الرئيسية للمنصة
1. **أداة التنبؤ الذكية (محاكي القرارات):** خوارزمية تحاكي نسبة الالتزام المتوقعة بناءً على بيئة التنفيذ والعدد المستهدف، وتصدر توصيات فورية.
2. **لوحة الأداء التاريخي:** لوحة بيانات تفاعلية تستخرج "استنتاجات ذكية" تلقائية لمقارنة أداء البرامج (حضورياً وعن بعد).
3. **المستشار الذكي (AI Assistant):** وكيل ذكي مدمج يجيب على استفسارات الإدارة التنفيذية فورياً لدعم اتخاذ القرار.
